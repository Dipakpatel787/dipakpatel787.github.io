# Dipak Patel — Portfolio Website

A responsive, single-page professional portfolio built with HTML and CSS.

## Files
- `index.html` — website
- `assets/profile.jpg` — profile photo
- `assets/Dipak-Patel-CV.pdf` — optional CV file (add your own PDF)

## Preview locally
Open `index.html` in a modern browser.

## Before publishing
1. Review every employment date, job title and project description.
2. Verify claims and metrics; remove anything that cannot be substantiated.
3. Replace the sample Google Play Store link with the exact app listing.
4. Add a CV PDF to `assets/Dipak-Patel-CV.pdf`.
5. Keep company/government code and restricted details private.
6. Decide whether you want your phone number visible publicly.
7. Add exact repository links for public demo projects.
